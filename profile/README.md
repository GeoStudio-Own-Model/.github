## Inside GeoStudio

GeoStudio is a local Windows geotech app with a named geo desk, a short analysis list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a model you already keep and holds only the analysis that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra analyses wait for their own title. GeoStudio starts with a local profile and does not need a complex account system.

The geo desk stays on a project you already own. Untitled analyses stay off the live list.

## Quick Start with GeoStudio

1. Open the last GeoStudio session on a model you keep, not a new empty analysis.
2. Read the geo desk and the last handoff.
3. Finish one visible slope view inside GeoStudio.
4. Write what changed, then close with a shorter analysis list than you found.
5. If the desk feels crowded, drop anything that belongs to a different project.
6. Leave the geo desk on a model you already own.
7. If an analysis is not yours, leave it off the live list.
8. Keep the geo desk on a project you already keep.
